# Баланс тактик — исправления 2.6

## Выбор действий

`Match22.ai` сравнивает доступные действия по прежним факторам состояния, затем
выбирает через устойчивый softmax: `exp((score - maxScore) / temperature)`.
В `dist/config/balance.js` температура равна 0.18. Для каждого варианта сохраняются
оценка, вероятность столкновения и вероятность выбора действия. Бонус preferred
отделён от прочих весов: 0.04. Ненулевые стилевые бонусы/штрафы — 0.03–0.04.
Удалены дополнительный бонус фарма для late и случайное возмущение оценок:
случайный выбор теперь задаётся самим распределением.

Одного уменьшения стилевых бонусов недостаточно: прежние прямые множители силы
и дохода тактик продолжали создавать перекос. Дополнительный множитель дохода
всех тактик теперь равен 1: экономический эффект остаётся в выбранном действии.
Фазовые бонусы смягчены, а различия предпочтений и ранних/поздних таймингов сохранены.

| Тактика | Ранняя / средняя / поздняя сила |
|---|---|
| Агрессивная | 1.02 / 1.02 / 1.00 |
| Контроль карты | 1.00 / 1.02 / 1.01 |
| Фарм до лейта | 0.98 / 1.00 / 1.04 |
| Раннее давление | 1.03 / 1.00 / 0.99 |

ИИ выбирает стартовую тактику после драфта. `tacticScores` учитывает собственный
`draftSlope` (средняя ранняя сила минус поздняя), соответствующий показатель
соперника, урон по строениям, инициацию, контроль и сейвы. Результат и основания
сохраняются в `tacticSelection26`. При ручном управлении выбор менеджера сохраняется;
начатая карта после загрузки не получает новую тактику задним числом.

## Потери в файтах

Удалён дополнительный гарантированный `+(smoke ? 0 : 1)` к числу жертв проигравшей
стороны. Осталась конфигурируемая базовая потеря плюс эффект локального перевеса.
При равных силах это одна базовая жертва, а не две.

`retaliation = 0.5`. Для каждого потенциального ответного удара:
`retaliationProbability = retaliation * (1 - winnerProbability)`.
При победе защитника `winnerProbability = 1 - p`, а не исходная вероятность атаки.
Близкий или неожиданный бой обходится победителю дороже уверенной победы.
Цели выбираются с весами уязвимости; мёртвые не отвечают. Ответные смерти ограничены
числом базовых жертв и необходимостью сохранить хотя бы одного победившего героя.
Реальные потери обеих сторон записываются в отчёт, включая отдельную потерю Аегиса.

## Общая информация и смоуки

Оба тренера получают снимок `lastActions22`, сделанный до выбора текущих действий.
Новый ручной приказ не передаётся сопернику как готовая подсказка в том же тике.
В `orderInfo26` сохраняются наблюдавшиеся и исполненные действия; в интерфейсе
показан последний завершённый план соперника. Это устраняет прежний доступ ИИ
к новому приказу игрока при использовании предыдущего приказа в автоматических картах.

Пополнение смоуков использует отдельный `actions.smokeInterval` (480 секунд).
`smokeCooldown` (180 секунд) относится к действию, `roshanStart` — к доступности
Рошана. Изменение одного параметра больше не меняет другой. Уже сохранённый
таймер пополнения не сбрасывается; новые карты берут стартовый таймер из конфига.

## Проверка 100 карт

```
node tests/ai-tactics.cjs
node tests/tactics-mirror.cjs
node tests/tactics-mirror.cjs --holdout
```

Основной прогон — 100 карт **на каждую из шести пар** (600 всего). На всех картах
один фиксированный драфт у обеих сторон: Juggernaut, Puck, Mars, Rubick, Oracle.
Навык и атрибуты 85, форма и мораль 80, усталость 10, комфорт 1; одинаковые
стартовые золото, предметы, уровни, строения и вижен. Позиции зеркальные.
Для каждого из 50 seed тактики меняются сторонами. Тактики в тесте фиксированы,
чтобы проверять именно их силу и поведение, а не качество автоматического подбора.

В тесте есть жёсткая проверка диапазона 40–60% **для каждой пары** и отсутствия
зависаний; не только усреднённый результат всей выборки.

| Первая тактика / вторая | Победы на 100 картах |
|---|---|
| Агрессивная / контроль | 55 / 45 |
| Агрессивная / late | 56 / 44 |
| Агрессивная / раннее давление | 46 / 54 |
| Контроль / late | 47 / 53 |
| Контроль / раннее давление | 46 / 54 |
| Late / раннее давление | 42 / 58 |

Дополнительная проверка на других seed: по 200 карт на пару, 1200 карт всего.
Доли побед первых тактик: 59.5%, 56%, 47.5%, 51%, 49.5%, 43%; все в диапазоне,
зависаний нет. Это воспроизводимые контрольные выборки, а не принудительные квоты
побед и не обещание того же процента в произвольных 100 играх.

`ai-tactics.cjs` отдельно проверяет устойчивость/температуру softmax, выбор не
только максимума, доступность действий, подбор по обоим драфтам, сохранение
ручной тактики, отсутствие утечки приказа, независимость смоуков от Рошана,
одну базовую жертву в равном файте и увеличение потерь победителя в близких боях.

Также проверены `match-v22`, `match-v26`, `balance-v26`, `fatigue-v26`,
`auto-fatigue-v26`, `recovery-v26` и архивный тест загрузчика `startup.cjs`.
Формат сохранений и правила усталости за серии не менялись.
