Игра Ancient Manager 2.6 для Mac: приложение и все игровые файлы находятся внутри установщика. Поддерживаются Apple Silicon и Intel.

Скачайте DMG, откройте его и перенесите Ancient Manager в «Программы». Приложение подписано локальной ad-hoc подписью; нотариальной подписи Apple пока нет. Если macOS заблокирует первый запуск, после проверки источника откройте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

Для переноса карьеры с сайта: «Сохранения → Скачать файл / скопировать код», затем импортируйте файл или код в приложении. Автоматической синхронизации между устройствами нет.

Нативный проект iPhone находится в native/ios. Для установки через TestFlight/App Store нужны Apple Developer, подпись и загрузка в App Store Connect. Архив для симулятора и неподписанный архив iPhone в Actions не являются устанавливаемой IPA.
