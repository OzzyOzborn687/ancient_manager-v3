# Ancient Manager: Mac и iPhone

Внутри приложений находится та же игра 2.6, со сложностью карьеры и исправленной защитой осады. Игровая логика и ресурсы загружаются из установленного приложения; интернет нужен для внешних ссылок и фотографий игроков, которые ещё не включены в локальный набор.

## Mac

Установщики DMG и ZIP для Intel и Apple Silicon публикуются в Releases после успешной сборки Native applications. Откройте DMG и перенесите Ancient Manager в «Программы».

Первая сборка имеет ad-hoc подпись, без нотариального заверения Apple. Если macOS блокирует первый запуск, проверьте, что скачали файл из этого репозитория, затем используйте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

Сохранения находятся в профиле приложения Ancient Manager в Library/Application Support. Закрытие окна и выход сохраняют текущую паузу карты. Для переноса с сайта используйте JSON или код в разделе «Сохранения».

Сборка на Mac: Node.js 24, затем из корня репозитория:

    npm --prefix native ci
    npm --prefix native run mac

## iPhone: нативное приложение

Используется Capacitor и WKWebView, с локально упакованной игрой, учётом безопасных областей экрана, остановкой симуляции в фоне и нативным меню «Поделиться» для сохранения JSON в «Файлы» или передачи на другое устройство.

Проект Xcode: native/ios/App/App.xcodeproj. Для подготовки на Mac:

    npm --prefix native ci
    npm --prefix native run ios:sync
    npm --prefix native run ios:open

В Xcode выберите свой Apple Developer Team и доступный вам Bundle Identifier, затем Product → Archive → Distribute App → App Store Connect. Через App Store Connect можно включить TestFlight и отправить версию на проверку App Store.

Оплаченный Apple Developer, подпись и право публикации обязательны для TestFlight/App Store. Сейчас аккаунт и подпись не подключены, поэтому ссылка на устанавливаемую IPA или TestFlight не создаётся. CI проверяет компиляцию симулятора и неподписанного архива; эти архивы нельзя просто установить на обычный iPhone.

Иконка для iOS кодируется без альфа-канала на Mac. PrivacyInfo.xcprivacy описывает использование файловых меток времени и UserDefaults. Игровые сохранения остаются на устройстве; автоматической синхронизации между Mac, сайтом и iPhone нет.

## Проверки

- tests/native-adapter.cjs: нативный экспорт JSON, восстановление исходных байтов, пауза/сохранение в фоне и обычный браузер.
- native/tests/desktop.cjs: настоящий Electron, два запуска с сохранённой карьерой, офлайн-загрузка, перенос JSON и изоляция renderer.
- CI Native applications: универсальный Mac, проверка обеих архитектур и подписи; iOS Simulator и unsigned archive.
