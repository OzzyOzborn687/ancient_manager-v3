# Автоматическая защита и ранняя осада — 2.6

Исправлены две причины поражений без защиты: ручной план держал свободных героев на прежних занятиях, а после разрушения башни фронт осады оставался готовым к следующему строению.

## Поведение

- Объявленные «Осада» и «Фокус Древнего» вызывают автоматическую защиту у обеих сторон. Используется одинаковый снимок завершённого тика; скрытые текущие приказы не читаются.
- У T1 собираются позиции 2/3/4; у T2 — 1/2/3/4; у базы и Древнего — все пять. Доступные TP тратятся, остальные герои идут пешком. Мёртвые и занятые боем не перемещаются мгновенно.
- Доступный TP прерывает старый пеший переход. Уже потраченный TP не появляется снова.
- Ручной приказ сохраняется. После ухода угрозы герои продолжают его; сообщение о временной защите видно в матч-центре и журнале.
- Входящий урон по своей постройке поддерживает тревогу даже после смены приказа атакующим.
- После T1/T2 нужен новый фронт и перегруппировка. Повторное нажатие осады не обходит эти условия.
- До 13-й минуты T2 получает 15% урона осады. Это раннее укрепление, а не бессмертие уже повреждённой башни. Условие видно в подсказке приказа.

Автоматическая защита увеличивает число боёв перед строениями. Для сохранения окон осады и камбеков скорректированы коэффициент урона по зданиям от купленных предметов и влияние разницы силы на боевую вероятность. Базовые рейтинги игроков не изменяются. Все значения находятся в dist/config/balance-v8.js.

## Контрольные результаты

| Проверка | Результат |
| --- | --- |
| Осада / Древний, обе стороны | Свободные герои возвращаются с настоящим TP и временем перехода |
| Занятые и мёртвые | Телепортации из боя или до возрождения нет |
| Ранний T2 | Здоровая башня переживает повторные осады на 10–12-й минуте |
| Между башнями | Повторный приказ не сбрасывает перегруппировку |
| Сохранение | Защита продолжает тот же расчёт после загрузки |
| Зеркало, 200 карт | 54% побед первой стороны; средняя длительность 60,96 мин.; зависаний нет |
| Фаворит 90 против 80, 200 карт | 73,5% побед |
| Слабая команда с решениями, 200 карт | 49,5% побед |
| Шесть пар тактик, по 100 карт | 40–53% |
| Браузер | Возврат пяти героев к Древнему проверен через настоящий матч-центр |

A/B дополнен двумя ситуациями: укреплённая высокая земля и гонка открытых баз. Они проверяют цену необдуманной осады и пользу фокуса Древнего вместо сноса бараков. Старые четыре ситуации и строгая проверка отсутствия доминирующего приказа сохранены.
