# V8.0 BETA

## Развитие
Одна каноническая шестёрка навыков, согласованная с исходным OVR без скачка рейтинга при миграции; старая ежедневная прибавка OVR отключена. Три шкалы по100: тренировки/опыт/разбор. Цикл повышает взвешенный OVR до1 в пределах потенциала,60% вклада фокусу и40% остальным, насыщенные навыки перераспределяют долю. Базовые занятия1,2/1,8; разбор3; внутренняя практика0,4 тренировок+1,5 опыта; официальные карты4/4,5; КВ1,5. Коэффициенты OVR/потенциала/энергии/штаба; лимиты опыта12/день35/неделю, КВ6/день12/неделю. Разбор заменяет тренировочный день, усталость+2, форма+0,05, мораль+0,10. Возраста нет. Основные кнопки и шкалы — в тренировках, персональные шкалы — в профиле.

## VALE INSIDE
Отдельная вкладка Alex Vale и переход из новостей. Сохраняемые стадии интереса/переговоров/сближения/срыва, подтверждённые реальные переходы с суммой. Чёрно-янтарные шаблоны с аватаром AV, BREAKING 🚨, фото/логотипами/маршрутом; специальные арты с кубком для сенсационных чемпионств и последовательных титулов. Заголовки капсом с12 сохраняемыми эмоциональными вариантами. Официальные клубные посты появляются через2–3 игровых дня или раньше после официальной серии с новичком. Возникшие до установки события не выдумываются задним числом. Позиция команды для сенсации фиксируется по сезонным очкам с тай-брейком Elo при первом результате турнира.

## Услуги
Семь новых услуг в отдельной вкладке, существующие три сохранены. Цены: специалист15k, внешний аналитик35k, герой12k, драфт20k, психолог18k, анализ сделки8k, аудит25k. Занятия заменяют день, не суммируются с обычной тренировкой. Отчёты фиксируют данные заказа, драфт/аудит готовы на следующий день, анализ сделки сразу. Учтены ограничения повторов и резерв трансферного бюджета; в отчётах о драфте явно указан доступный источник — пулы героев. Платного готового OVR нет.

## Проверка
Unit beta8: прирост очков без побед, один цикл, отсутствие повторного дня, лимит опыта, чистый предпросмотр, реальные цены/повторы услуг, инсайдер до официального поста, перенос сохранения. Браузер: разбор, все7 услуг, арт Вейла, рынок, тренировки и новые вкладки на1440/390/320, сохранение/загрузка без ошибок. Startup с предыдущими версиями/активной картой/отказом хранилища пройден. Переговоры V7 проверены отдельно. Числа являются стартовым балансом BETA; полный сезон на реальном Safari пока не замерен.
