# Инструкции для работы с Ancient Manager

Это существующая игра Ancient Manager v2.1. Прочитай README_RU.md и исходники перед изменениями.

- Меняй этот проект по заданию пользователя, сохраняя остальные работающие возможности.
- Это buildless HTML/CSS/JS; dist/ — редактируемый исходный код, не удаляй её как артефакт сборки.
- Скрипты используют общий глобальный контекст и последовательно расширяют/переопределяют функции. Сначала изучи порядок script в index.html и последние определения функций. Не считай старые файлы неиспользуемыми только по номеру версии.
- Не объединяй и не удаляй слои движка без проверки зависимостей.
- Сохраняй совместимость карьеры, турниров и импортируемых JSON. При изменении схемы предусматривай миграцию и повторный запуск без повторного начисления наград/штрафов.
- У игры русскоязычный интерфейс. Существующие календарь 2026/2027, развитие, форма, потенциал, состав, трансферы, досье, награды и режимы матчей должны продолжить работать.
- Не выдумывай сведения о реальных игроках; проверяй запрашиваемые реальные данные по источникам и отмечай пробелы.
- Секретов, токенов публикации, истории Git и пользовательских сохранений в архиве нет. Доступа к ChatGPT Sites архив не даёт.
- Проверки запускай из корня проекта. Сообщай точные команды и результат; если проверку выполнить не удалось, скажи об этом явно.
- В конце верни полный обновлённый ZIP с сохранённой структурой dist/, tests/, документацией и кратким CHANGELOG. Не ограничивайся фрагментами кода.
