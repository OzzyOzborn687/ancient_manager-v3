# Ancient Manager v2.1 — исходный проект для Claude

## Запуск
Это статическая игра на HTML/CSS/JavaScript без сборки и npm-зависимостей.
Папка dist содержит именно исходный код, а не скомпилированные файлы.
1. Распакуйте ZIP.
2. Откройте терминал в корне Ancient-Manager-v2.1.
3. Выполните: python3 -m http.server 8000 --directory dist
   На Mac также можно использовать python вместо python3, если он установлен под этим именем.
4. Откройте http://localhost:8000 в браузере.
Для остановки сервера нажмите Ctrl+C.

## Структура
- dist/index.html — точка входа; порядок загрузки скриптов имеет значение.
- dist/game.js — базовая игра, данные и состояние карьеры.
- dist/engine-v4.js … engine-v7.js — последовательные расширения матчевого движка.
- dist/tournaments-v6.js — турниры.
- dist/career-v1.js, tactics-v1.1.js, world-v1.2.js, world-v1.3.js — карьера и механики.
- dist/ti-event.js, player-retirement.js — событие TI и завершение карьеры.
- dist/interface-v2.js/.css — интерфейс v2.0 и досье.
- dist/calendar-v21.js — исторические календарные шаблоны.
- dist/development-v21.js — база, штаб, форма, потенциал и подготовка.
- dist/interface-v21.js/.css — интерфейс v2.1.
- dist/startup.js — запуск и восстановление сохранений.
- dist/player-photos-v2.js и assets/ — фотографии и эмблемы; часть изображений загружается с внешних сайтов и требует интернета.
- tests/ — проверки Node.js, без установки пакетов.

## Проверки
Запускайте из корня проекта с установленным современным Node.js:
node tests/startup.cjs
node tests/interface-v2.cjs
node tests/development-v21.cjs
Остальные тесты относятся к отдельным этапам разработки; их актуальность после новых изменений нужно оценивать отдельно.
Эти проверки не заменяют визуальную проверку в браузере.

## Сохранения и публикация
Карьеры находятся в хранилище браузера и не включены в исходники.
Чтобы перенести свою карьеру с опубликованного сайта на localhost, используйте экспорт/импорт JSON во вкладке «Сохранения».
Работайте с копией сохранения при изменении его формата.
Архив не предоставляет Claude доступ к управлению ChatGPT Sites и не публикует изменения автоматически.
