# Matchday — BETA V6.0

The approved black/ivory/lime UI is now enabled on the standard game URL.

The home hero uses the current club emblem instead of a carry portrait. Lineup portraits remain in their roster strip. All registered tabs use the same Matchday fonts, navigation, panels, buttons, tables and responsive spacing. Existing engine actions and save data are unchanged.

Animation CSS/JS in dist/v52 is untouched. New theme variables are scoped to app content; animated dialogs retain their original computed styles.

See PATCH_6_0_BETA.md and tests/browser/beta6.cjs for release scope and validation.
