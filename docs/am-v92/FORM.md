# V9.2 — форма и подготовка

Форма игрока ограничена диапазоном 35–99. Значение 75 нейтрально. Система OVR (две копилки), SIN, мораль, контракты и календарь турниров сохраняют свои правила. Усиление от формы не записывается в OVR.

## Ежедневная подготовка

Расчёт выполняется один раз на игрока за календарный день, по форме и усталости **до** занятия:

```
форма = clamp(форма + прирост − спад, 35, 99)
прирост = база × интенсивность × усвоение × min(1.5, штаб × буткемп)
```

| Форма до занятия | База за день | Спад за день |
|---|---:|---:|
| <70 | 2.0 | 0 |
| 70–<85 | 1.2 | 0 |
| 85–<92 | 0.7 | 0.1 |
| 92–<97 | 0.4 | 0.2 |
| 97–99 | 0.2 | 0.3 |

Обычная тренировка: ×1, интенсивная: ×1.25. Усталость до 25 включительно: ×1; до 45: ×0.75; до 65: ×0.4; выше 65: ×0. Обычная нагрузка +3 усталости, интенсивная +6, отдых −12; существующие улучшения восстановления применяются отдельно.

Штаб уровней 1–5: ×1 / 1.05 / 1.10 / 1.15 / 1.20. Буткемпы: ×1.15 / 1.30 / 1.50. Максимум общего множителя штаба и буткемпа — ×1.5. Прежней плоской прибавки формы буткемпа нет. Цены, длительность, дополнительное восстановление и возвраты прежние.

Отдых и пропуск дня не дают тренировочного прироста, но ежедневный спад действует. Запланированная услуга заменяет тренировку: психолог сохраняет +0.1 формы, внутренняя практика +0.15; другие услуги не добавляют форму. Спад применяется и в эти дни. Свободные агенты получают только календарный спад.

Это позволяет быстро восстановить низкую форму, но для достижения и поддержания 99 нужны восстановление, интенсивная подготовка/буткемп и хорошие серии. Например, на пике обычная тренировка без бонусов даёт 0.2−0.3=−0.1 формы.

## Личное выступление за серию

Для реально смоделированных карт накапливаются статистики участников, сохраняемые вместе с незавершённой серией. После записи результата всей BO2/BO3/BO5:

```
KP = (убийства + помощи) / max(1, убийства команды)
оценка = 0.5 × (KP − KP соперника той же позиции)
       + clamp(0.08 × (смерти соперника − смерти игрока) / карты, −0.3, 0.3)
       + экономика
экономика = clamp(0.5 × ln((NW + 1)/(NW соперника + 1)), −0.4, 0.4)
```

Экономика применяется только к позициям 1–3; саппорты не обязаны фармить или набирать убийства. Оценка ≥0.15 даёт +0.4 формы, ≤−0.15 даёт −0.3, иначе +0.1. Победа сама по себе не гарантирует хорошее личное выступление. Если ускоренная модель серии не создаёт личную статистику, используется обычная оценка +0.1, с явной пометкой в объяснении; статистика не выдумывается. За технический результат пропущенного турнира бонус не выдаётся.

КВ: половина изменения за всю серию, положительный прирост ограничен +0.2 на игрока за день. Итоговая форма всегда ограничена 99. Старая потеря за проигранную карту и отдельный процентный штраф за место на турнире убраны.

## Влияние на матч

```
вклад формы = 0.25 × (форма − 75)
множитель боевой силы героя = exp(коэффициент OVR × вклад формы)
```

Это эквивалент очков силы, а не изменение сохранённого OVR. При 99: +6; при 75: 0; при 55: −5. Усталость учитывается отдельным существующим множителем один раз. Прежний слабый множитель формы заменён, а не сложен с новым. Быстрые региональные серии используют обновлённую силу команды без второй надбавки формы. Карты, начатые до V9.2, сохраняют прежний расчёт до завершения; новые карты получают версию правила в снимке.

В тренировках показаны прогноз прироста, спада и итогового изменения, правила поддержания формы и причина последней оценки за серию. В матч-центре показан вклад формы обеих команд, зафиксированный при создании карты.
