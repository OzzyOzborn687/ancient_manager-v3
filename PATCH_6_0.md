# V6.0 — Global interface update

Matchday becomes the full interface language: matte charcoal, ivory, acid lime, bundled Roboto Condensed ExtraBold italic headings and monochrome roster photography.

## Screens
- Rebuilt squad view: five role-numbered photographic cards, select-in-place details, reserve slots, bench/contracts tabs, current OVR/SIN/form/energy. Profiles, comparison, contracts and table mode use existing handlers.
- New contextual layouts for scouting, performance/training, competition and finances with actual career data. Shared editorial page mastheads, cards, tables, trophy and bracket treatments on all registered tabs.
- Existing fan support, archive, saves and all navigation remain available. No fabricated players, statistics or forecasts.

## Animation and dialogs
- Transfer, tournament intro, eliminations and grand final share Matchday backgrounds, fonts, lime actions and flat framing; transfer portraits are monochrome, price remains the actual fee.
- The International presentation, sponsor messages and regular confirmation/draft dialogs adopt the same type and palette.
- Red ELIMINATED is retained as a meaningful result colour. Existing timing, triggers, acknowledgement, reduced-motion and save behaviour remain.

## Validation
All registered screens checked at desktop/mobile widths, no horizontal page overflow or runtime errors. Browser checks cover selection without career mutations, reserve/contracts tabs, navigation, next-day action, save/reload and four broadcast dialog themes. Existing startup, draft, transfer, tournament and elimination regression checks retained. Interface tests updated for new structure/version.

The V5.2 D tournament-results concepts are now implemented in V6.0; see PATCH_6_0_RESULTS_D.md. No new result calculation mechanics introduced. Match formulas, OVR, SIN, economics, training and save schema are unchanged.
