# V9.1 BETA

- Рост OVR: для завершения цикла требуются только тренировки 100/100 и игровой опыт 100/100. Анализ не является обязательным условием и не показывается третьей шкалой. Скорости накопления, ограничения опыта, потенциал и распределение прибавки по характеристикам сохранены. Старое поле analysis читается для совместимости сохранений.
- Клуб → Карьера: между турнирами/КВ менеджер может создать собственный микс, задав уникальное название, тег и регион. Перед выходом показывается подтверждение последствий. Прежний клуб сохраняет игроков, средства и продолжает существовать в мире; результаты прежнего этапа доступны в архиве карьеры.
- Микс начинает с пустой основой и $1 200 000. Бюджет прежнего клуба не переносится. Начальная база/тренер — 1/75. Спортивный ориентир для первых подписаний — OVR 75; далее работает фактический уровень состава. Трансферные цены, ответы клубов, амбиции, сроки и зарплаты используют действующие переговоры V7.
- Подписанный основной игрок может занять пустую позицию. До набора пяти позиций календарь и переговоры доступны, матчи и КВ заблокированы; незавершённый микс исключён из рейтингового отбора. Собранная пятёрка участвует по обычным правилам. Создаётся один собственный микс в рамках карьеры; свободная смена любых клубов в этот патч не входит.
- Неполный состав разрешён валидатором только для помеченного пользовательского микса; у обычных клубов по-прежнему требуется ровно один основной игрок каждой позиции. Добавлена проверка метаданных архива менеджера.

Проверки: beta8, interface-v9, draft-update; browser/v91 (реальное создание через форму, 21 проверка адаптивных экранов, сохранение пустого/неполного состава, переговоры со свободным агентом и клубом, 15 дней, перезагрузка, допуск полной пятёрки и десять пиков); browser/market7. Для проверки допуска матча последние три позиции заполняются тестовыми назначениями существующих свободных агентов, первые две подписываются настоящими переговорами.
